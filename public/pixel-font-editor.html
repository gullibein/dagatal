Controls:

• Left-click + drag: Draw black pixels

• Right-click + drag: Erase pixels (draw line eraser)

• Right-click on canvas: Show context menu

Features:

• Auto-detects grid size from imported fonts (5x5 to 16x16)

• Extended Latin support (incl. Icelandic: Þ, Ð, Æ, Œ, á, é, í, ó, ú, ý, þ, ð, æ, œ)

• Import TTF, OTF, WOFF2, WOFF fonts
